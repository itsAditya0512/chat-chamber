# Clone the Project and initialise the project by installing the dependencies :-

**1. Clone the project into your directory :** 


   *git clone https://github.com/itsAditya0512/chat-chamber.git*
  
## For Fronted :
 
**2. Change the current directory to the directory called client :**


   *cd client*
   
**3. Install the node modules :**


   *npm init*
   
**4. To run the project :**


   *npm run dev*
   
**5. To build the project :**


   *npm run build*
